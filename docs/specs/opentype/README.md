# OpenType — первичные источники для M10

HTML-копии разделов Microsoft OpenType 1.9.1 загружены 2026-10-16:
https://learn.microsoft.com/en-us/typography/opentype/spec/

otff — каталог и типы; head, hhea, hmtx, maxp — метрики; loca/glyf —
контуры; cmap — Unicode; ttch01 — квадратичные кривые и non-zero winding.
Точные URL и SHA-256 загруженных файлов — `sources.json`.
