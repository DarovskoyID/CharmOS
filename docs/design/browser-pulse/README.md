# «Пульс» — дизайн-пакет браузера CharmOS

В этой папке собрана утверждённая дизайн-концепция браузера без реализации.

## Состав

- `images/home.png` — новая вкладка.
- `images/settings.png` — основные настройки.
- `images/account.png` — аккаунт и безопасность.
- `images/appearance.png` — персонализация и управление карточками.
- `SPECIFICATION.md` — правила интерфейса и визуальные токены.
- `PROMPT.md` — мастер-промпт для воспроизведения и развития дизайна.

При создании новых экранов следует использовать `PROMPT.md` вместе с одним из
готовых изображений как визуальным референсом.
