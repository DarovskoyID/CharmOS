# ABI: ввод (syscall ABI v1.8)

**Статус: ЗАФИКСИРОВАН, v1.8 (2026-10-16).** Решения автора —
журнал `plans/os-gui-design.md` (2026-10-15): драйвер PS/2 в ядре; два кольца
(драйвер → компоновщик → окно в фокусе).

## 1. Хендл `Input`

- Объект ядра «устройства ввода» (сейчас PS/2: клавиатура и мышь, 8042 —
  `docs/specs/ibm-ps2-common-1990.pdf`). Ядро кладёт его только в стартовое
  сообщение init с ролью **`Input` = 10**; init передаёт его компоновщику.
- Права: `Write` — `input_attach`; `Read` — привязка к порту; `Duplicate |
  Transfer` — как обычно.

## 2. Вызов

| № | Имя | Аргументы | `RDX` при успехе |
|---|---|---|---|
| 67 | `input_attach` | `input, vmo` | — |

- `vmo` — кольцо событий (§3), размер — степень двойки страниц, не больше
  64 КиБ. Ядро отображает его у себя и пишет туда события; прежнее кольцо (если
  было) отпускается. `Input` привязывается к порту (`object_bind`): пакет
  **`kPacketInputReadable` = 10** — в кольце есть новые события (как у консоли,
  console.md §1: пакет одноразовый, привязку обновляют после чтения).

## 3. Кольцо событий (общее: ядро → компоновщик и компоновщик → окно)

Заголовок — 64 байта, дальше записи по 24 байта.

| Смещение | Поле | Кто пишет |
|---|---|---|
| 0 | `uint32 magic` = `"INPR"` | создатель кольца |
| 4 | `uint32 version` = 1 | создатель |
| 8 | `uint32 capacity` — записей (степень двойки) | создатель |
| 12 | `uint32 reserved` | — |
| 16 | `uint32 head` — сколько записей прочитано | читатель |
| 20 | `uint32 tail` — сколько записей записано | писатель |
| 24 | `uint32 dropped` — потеряно при полном кольце | писатель |
| 28 | — до 64: нули | |

- `head` и `tail` растут без ограничения, запись — `[tail % capacity]`;
  полное — `tail - head == capacity` (новое событие отбрасывается,
  `dropped` растёт). Писатель публикует запись release-записью `tail`, читатель
  — acquire-чтением.

### 3.1. Запись (24 байта)

| Смещение | Поле | |
|---|---|---|
| 0 | `uint64 time_ns` | монотонное время события (`now_ns`) |
| 8 | `uint16 type` | 1 — клавиша, 2 — движение указателя, 3 — кнопка указателя, 4 — колесо |
| 10 | `uint16 code` | клавиша: HID Usage ID страницы Keyboard/Keypad (0x07, `hid-usage-tables-1.12.pdf` §10); кнопка: 1 — левая, 2 — правая, 3 — средняя |
| 12 | `int32 value` | клавиша/кнопка: 1 — нажата, 0 — отпущена, 2 — автоповтор; колесо: шаги |
| 16 | `int32 x` | движение: dx (вправо +); в кольце окна — координата в окне |
| 20 | `int32 y` | движение: dy (вниз +); в кольце окна — координата в окне |

- Коды клавиш — HID Usage, а не скан-коды PS/2: ядро переводит набор 2 в
  Usage, и будущий USB HID (юзерспейс) пишет те же коды.
