# ABI: ввод от USB-драйвера (syscall ABI v1.10)

**Статус: ЗАФИКСИРОВАН, v1.10 (2026-10-16).** Рабочее решение Codex по
поручению автора продолжать дорожную карту самостоятельно. Расширяет v1.8,
не меняя InputEvent, input_attach или оконный протокол v2.

## Вызов 68: device_input

`device_input(device, const InputEvent* event)` принимает одно событие.

- Нужен Device с правом Write, принадлежащий функции PCI класса 0x0c0330
  (xHCI). Обычное приложение или иной PCI-драйвер ввод подать не может.
- Ядро копирует InputEvent (input.md §3.1), проверяет его, заменяет time_ns
  своим монотонным временем и помещает в то же кольцо, куда пишет PS/2.
- Допускаются Key (usage 4–0xe7, value 0/1/2, x=y=0), Motion (code=value=0,
  dx/dy от −32768 до 32767), Button (code 1–3, value 0/1, x=y=0), Wheel
  (code=0, value от −127 до 127, x=y=0).
- Успех — Ok, в том числе когда компоновщик ещё не подключён или кольцо
  заполнено (обычный учёт dropped). Другие результаты: BadHandle,
  WrongType, AccessDenied, BadAddress, InvalidArgs.
- Старый ABI остаётся действительным; abi_version возвращает 1.10.

Драйвер разбирает USB HID в юзерспейсе по HID 1.11 boot protocol. Ядро
не читает USB-дескрипторы и не управляет USB-контроллером.
