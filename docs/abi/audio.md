# ABI: вывод PCM (syscall ABI v1.11, протокол audio v1)

**Статус: ЗАФИКСИРОВАН (2026-10-16).** Рабочее решение Codex по поручению
автора продолжать M10 самостоятельно. Минимальный PCM-вывод, без захвата,
микширования и регулировки громкости приложениями. Формат: 48000 Гц,
два канала, signed little-endian 16 bit, 4 байта на кадр.

## 1. Подключение

Ядро выдаёт только init объект Audio с ролью **Audio = 12**, правами
Duplicate | Transfer | Write. Init может передавать его обычным процессам;
libc: charm_audio(), CHARM_GIVE_AUDIO = 128.

Вызов **69 audio_open(audio)** возвращает клиентский конец двери драйвера
(Write | Transfer | Duplicate). Без драйвера — NotFound; неверный хендл,
тип или права — BadHandle/WrongType/AccessDenied; память — NoMemory.

Драйвер `class = "audio"` создаёт дверь, передаёт клиентский конец ядру
по стартовому каналу сообщением из четырёх байт `aud1` с одним хендлом.
Ядро хранит дверь до завершения драйвера. Приложение получает её по
audio_open, создаёт свой канал и посылает HELO с его вторым концом.

## 2. Сообщения (include/abi/audio.hpp)

Все числа little-endian, естественное выравнивание, без скрытых указателей.

| Тип | Поля | Хендлы |
|---|---|---|
| 1 HELO | uint32 type, version=1 | канал подключения |
| 101 WELCOME | uint32 type, version=1, rate=48000, channels=2, bits=16, max_frames=1024 | — |
| 2 PLAY | uint32 type, frames (1..1024); затем frames×4 байт PCM | — |
| 102 DONE | uint32 type, frames; int32 status (Status) | — |

Один PLAY в работе на соединение; после DONE клиент может отправлять
следующий. DONE означает завершение DMA-периода и остановку потока:
буфер скопирован в частную DMA-память драйвера до запуска. Короткий PLAY
дополняется тишиной до 1024 кадров. Запросы сериализованы, микширования нет.
Это исходная реализация, не обещание непрерывного gapless-потока.
При неправильном сообщении соединение закрывается. При падении драйвера
канал закрывается, новое подключение — через audio_open после перезапуска.

## 3. Безопасность

Приложению не выдаются Device, MMIO, IRQ или DMA; ядро PCM не разбирает.
Audio разрешает только получение двери вывода. Роль и новый вызов добавлены
минорной версией 1.11, старые интерфейсы не меняются.
