# ABI: формат initrd

**Статус: ЗАФИКСИРОВАН, версия 1.0 (2026-10-14).**

Архив файлов, который загрузчик кладёт в память как есть (`\charmos\initrd`,
поля `initrd_base/initrd_size` в `BootInfo`, docs/abi/boot.md §5). Ядро
только читает его. Собирается утилитой `tools/mkinitrd` (хост). Код разбора —
`lib/initrd`, структуры — `include/abi/initrd.hpp`.

Формат намеренно минимален: плоский список файлов без каталогов, прав и
сжатия. Всё, что сложнее, — дело файловой системы (M6).

## Раскладка

Все числа little-endian.

```
смещение 0:   Header (32 байта)
смещение 32:  Entry[entry_count] (по 64 байта)
далее:        данные файлов, каждый с границы 16 байт
```

```cpp
struct Header {          // 32 байта
  char magic[8];         // "CRMSINIT"
  uint32_t version;      // 1
  uint32_t entry_count;
  uint64_t total_size;   // размер всего архива в байтах
  uint64_t reserved;     // 0
};

struct Entry {           // 64 байта
  char name[48];         // UTF-8, завершающий 0 обязателен, остаток — нули
  uint64_t offset;       // от начала архива, кратно 16
  uint64_t size;         // байт
};
```

## Правила проверки (ядро отвергает архив целиком при нарушении)

- `magic` и `version` совпадают; `total_size` не больше размера, переданного
  загрузчиком.
- Таблица записей помещается в архив.
- У каждой записи: `name` содержит 0 в пределах 48 байт и не пуст;
  `offset` кратен 16; `[offset, offset + size)` лежит после таблицы записей и
  внутри `total_size` (с проверкой переполнения).
- Имена уникальны.
