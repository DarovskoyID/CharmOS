# ABI: сетевые драйверы (syscall ABI v1.4)

**Статус: ЗАФИКСИРОВАН, v1.4 (2026-10-14).** Минорное расширение v1.3,
старое не меняется. Основа — решение автора от 2026-10-14 (журнал): кольца
RX/TX и пул буферов в VMO, видимый устройству через IOMMU. Устроено по
образцу docs/abi/block.md.

## 1. Модель

- Сетевой драйвер — драйвер класса `net` (манифест: `class = "net"`,
  driver.md §7). Один драйвер — один сетевой интерфейс.
- Стек TCP/IP — в ядре; драйвер только передаёт кадры Ethernet II
  (без FCS) между устройством и ядром.
- Буферы кадров выделяет **драйвер** (`dma_alloc`, они видны его
  устройству) и отдаёт ядру тем же VMO: ядро копирует кадры в буферы и из
  них. Копирование одно на кадр в каждую сторону (правило 9: нулевое
  копирование — после замеров).

## 2. Рукопожатие (по стартовому каналу, после `"device"`)

1. Драйвер инициализирует устройство и шлёт `NetHello` (§5.1) и два
   хендла: VMO буферов (`Read | Write | Map`) и VMO колец (то же).
2. Ядро отвечает `"ok"` и одним хендлом — своим концом канала уведомлений
   (§4), или `"reject"` (без хендлов) — драйвер завершается.

## 3. Кольца (VMO колец, 2 страницы)

| Смещение | Что |
|---|---|
| 0 | `NetRingHeader` (§5.2) |
| 256 | `Slot tx[64]` по 16 байт — кадры ядра на отправку (пишет ядро) |
| 1280 | `Slot rx_free[64]` — пустые буферы для приёма (пишет ядро) |
| 2304 | `Slot rx_done[64]` — принятые кадры (пишет драйвер) |
| 3328 | `Slot tx_done[64]` — отправленные, буфер свободен (пишет драйвер) |

- Каждое кольцо — индексы `head`/`tail` в заголовке, свободно растущие
  `uint32_t`, позиция = индекс mod 64; порядок памяти — как в block.md §3.
- Буфер `i` пула — байты `[i · buffer_size, (i + 1) · buffer_size)` VMO
  буферов. Каждый буфер в каждый момент принадлежит ровно одной стороне:
  ядру (свободен или заполняется), драйверу (в `tx`/`rx_free`, пока не
  вернулся через `tx_done`/`rx_done`).
- В начале ядро кладёт в `rx_free` половину буферов.

## 4. Уведомления

Как в block.md §4: канал-«звонок» и флаги `driver_wants_kick` /
`kernel_wants_kick` в заголовке. Изменение состояния линии (`link_up`)
драйвер тоже сообщает звонком.

## 5. Структуры (little-endian, `static_assert` в include/abi/net.hpp)

### 5.1. `NetHello` (32 байта)

| Смещение | Поле | |
|---|---|---|
| 0 | `char magic[4]` | `"net1"` |
| 4 | `uint8_t mac[6]` | |
| 10 | `uint16_t mtu` | без заголовка Ethernet; 1500 |
| 12 | `uint32_t buffer_size` | ≥ 1518, кратно 64 |
| 16 | `uint32_t buffer_count` | 64..1024 |
| 20 | `uint32_t flags` | 0 (резерв под offload) |
| 24 | `uint64_t reserved` | 0 |

### 5.2. `NetRingHeader` (256 байт)

| Смещение | Поле |
|---|---|
| 0 | `uint32_t tx_head, tx_tail` |
| 8 | `uint32_t rx_free_head, rx_free_tail` |
| 16 | `uint32_t rx_done_head, rx_done_tail` |
| 24 | `uint32_t tx_done_head, tx_done_tail` |
| 32 | `uint32_t driver_wants_kick, kernel_wants_kick` |
| 40 | `uint32_t link_up` | 1 — линия есть (пишет драйвер) |
| 44 | `uint8_t reserved[212]` |

### 5.3. `Slot` (16 байт)

| Смещение | Поле | |
|---|---|---|
| 0 | `uint32_t buffer` | номер буфера в пуле |
| 4 | `uint32_t length` | байт кадра (в `rx_free` — 0) |
| 8 | `int32_t status` | `tx_done`/`rx_done`: 0 или `IoError` |
| 12 | `uint32_t reserved` | 0 |

## 6. Падение драйвера

Пул и кольца уходят вместе с драйвером (они его VMO); незавершённые
отправки ядро считает потерянными (TCP повторит, UDP — потеря, как в
сети). Новый запуск — новое рукопожатие; MAC тот же — интерфейс тот же.

## 7. Исправление при реализации (2026-10-14)

В первоначальном тексте §3 VMO колец был «1 страница», но заголовок и четыре
кольца по 64 слота занимают 4352 байта. Исправлено на 2 страницы (8192
байта); смещения колец не меняются. v1.4 к этому моменту не был выпущен
(`abi_version` сообщал 1.3), поэтому новая версия не вводится.
