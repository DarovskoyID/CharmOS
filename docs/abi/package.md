# ABI: пакет программы (`.cpk`), v1

**Статус: ЗАФИКСИРОВАН, v1.6 (2026-10-15).** Решения автора —
журнал `plans/os-gui-design.md` от 2026-10-15 (M8.5).

Пакет — один файл: заголовок, таблица файлов, манифест, данные файлов,
подпись. Все числа — little-endian. Смещения — от начала файла.

## 1. Заголовок (64 байта)

| Смещение | Поле | |
|---|---|---|
| 0 | `char magic[4]` | `"CPK1"` |
| 4 | `uint16_t version` | 1 |
| 6 | `uint16_t flags` | 0 (резерв) |
| 8 | `uint32_t file_count` | до 4096 |
| 12 | `uint32_t manifest_size` | байт манифеста, до 64 КиБ |
| 16 | `uint64_t table_offset` | таблица файлов (§2), сразу за заголовком: 64 |
| 24 | `uint64_t manifest_offset` | манифест (§3) |
| 32 | `uint64_t data_offset` | данные файлов, выровнено на 8 |
| 40 | `uint64_t signed_size` | сколько байт от начала покрывает подпись |
| 48 | `uint64_t signature_offset` | = `signed_size`; за ней — конец файла |
| 56 | `uint64_t reserved` | 0 |

## 2. Таблица файлов (`file_count` записей по 344 байта)

| Смещение | Поле | |
|---|---|---|
| 0 | `char path[256]` | путь внутри программы, UTF-8, `/` — разделитель, без `..`, без начального `/`, дополнен нулями |
| 256 | `uint64_t offset` | смещение данных файла |
| 264 | `uint64_t size` | размер |
| 272 | `uint32_t mode` | бит 0 — исполняемый (ELF), остальные 0 |
| 276 | `uint32_t reserved` | 0 |
| 280 | `uint8_t sha512[64]` | SHA-512 содержимого файла (FIPS 180-4) |

Хеши файлов нужны, чтобы проверять **каждый запуск**: служба пакетов (§pkg.md)
хранит подписанные заголовок и таблицу рядом с установленной программой и
сверяет SHA-512 исполняемого файла перед `process_spawn`.

## 3. Манифест (TOML, как у драйверов, lib/manifest)

```toml
id = "org.example.hello"      # уникальное имя: [a-z0-9.-], до 64 байт
name = "Hello"                # для людей
version = "1.0.0"
exec = "bin/hello"            # путь из таблицы файлов (mode: исполняемый)
permissions = ["net", "files"] # что программа просит (§4)
```

## 4. Права (`permissions`)

| Право | Что получает программа при запуске |
|---|---|
| `net` | хендл `Net` (роль 4) с `Connect | Resolve` |
| `net-listen` | хендл `Net` с `Listen` (порты ≥ 1024) |
| `files` | свой каталог данных `/home/apps/<id>` как корень (роль 1) |
| `home` | весь `/home` как корень (роль 1) — все файлы пользователя; при подтверждении показывается отдельно, как опасное |
| `console` | консоль (роль 3) |

Без прав программа получает только свой каталог программы на чтение.
Права показываются пользователю при установке программы не из магазина.

## 5. Подпись

- `sig = Ed25519(private_key, SHA-512(bytes[0, signed_size)))` (RFC 8032,
  PureEdDSA над 64-байтным дайджестом). За подписью — 32 байта открытого
  ключа подписавшего: всего 96 байт после `signature_offset`.
- **Пакет магазина** — подписан ключом автора; открытый ключ зашит в службу
  пакетов. Ставится в закрытую область.
- **Любой другой** (без подписи — `signature_offset = 0`, или подписан чужим
  ключом) — ставится только вне закрытой области и только после
  подтверждения пользователя (pkg.md §3).

## 6. Инструмент `tools/sign` (хост)

`sign keygen <файл>` — пара ключей (закрытый остаётся у автора, вне
репозитория); `sign pack <каталог> <manifest.toml> <ключ> <out.cpk>`;
`sign verify <out.cpk> <открытый ключ>`.

## 7. Уточнения при реализации (2026-10-15)

- Подпись покрывает заголовок, таблицу файлов и манифест: `signed_size =
  data_offset`. Данные файлов защищены их SHA-512 в подписанной таблице.
  Так при каждом запуске проверяется только `package.sig` (подписанная
  часть + 96 байт блока подписи) и сам исполняемый файл — не весь пакет.
- Без подписи `signature_offset = 0`. Подпись — сразу после данных
  (выровнено на 8); данные каждого файла выровнены на 8.
- Раскладка — со `static_assert` в include/abi/package.hpp; разбор и
  проверка — lib/package; сборка — tools/sign.
