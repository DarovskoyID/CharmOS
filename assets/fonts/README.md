# Шрифты интерфейса

Неизменённые статические TrueType-файлы, выбранные автором CharmOS.
Лицензия каждого семейства SIL Open Font License 1.1 лежит рядом в OFL.txt.
Это данные; разбор и растеризация реализованы своим кодом в lib/font.

- Space Grotesk Regular/Medium: https://github.com/floriankarsten/space-grotesk
- JetBrains Mono Regular: https://github.com/JetBrains/JetBrainsMono

Постоянные URL с ревизиями источников и SHA-256 — `sources.json`.
