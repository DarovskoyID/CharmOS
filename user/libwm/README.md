# Клиент оконного протокола CharmOS v2

`charm::gui::Window` — один канал подключения и одно окно. Библиотека
проверяет версию, создаёт два VMO и кольцо ввода, отслеживает владение
буферами, освобождает хендлы и отображения при ошибке/закрытии.
Публичный заголовок — `charm/window.hpp`, цель CMake — `wm_client`.

1. `create(title, width, height)`; процессу нужна роль Wm от init.
2. Рисовать в `pixels(0)`, затем `present(0, damage)`.
3. `wait(&event)`; на `FRAME_DONE` рисовать в `pixels(event.value)`.
4. На `INPUT` вызывать `next_input` до false перед следующим ожиданием.
5. На `CLOSE_REQUEST` выйти из цикла, вызвать `close` или дать сработать
   деструктору. Закрытие повторно безопасно.

`pixels` возвращает nullptr для буфера компоновщика; `present` отвергает
повторную отправку занятого буфера и неверный прямоугольник. Свои события
доставляются в исходном формате `abi::wm::WindowEvent`. Ожидание может
вернуть Interrupted, TimedOut или PeerClosed; приложение решает, что делать.
Рукопожатие ограничено пятью секундами.

Пример приложения — `user/bin/wdemo`. Проводного ABI библиотека не расширяет;
создание нескольких окон возможно отдельными объектами/соединениями.
