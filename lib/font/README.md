# TrueType в CharmOS

Свой код по Microsoft OpenType: сохранённые разделы — `docs/specs/opentype`.
Внешние библиотеки и исходники растеризаторов не используются.

`Face` ссылается на неизменяемые байты шрифта; они должны жить дольше него.
`open` проверяет каталог, границы таблиц, loca и Unicode cmap 4/12.
`rasterize` получает память изображения и `Workspace` от вызывающего,
возвращает `false` при повреждении, неподдерживаемом шрифте или лимите.
Ширина/высота на входе — ёмкость, на выходе — размер глифа; stride не меняется.
left/top задают смещение от начала строки и базовой линии. Значения alpha 0–255.

Поддержаны простые и составные glyf, квадратичные кривые с неявными точками,
привязка компонентов по точкам, преобразования, hmtx, UTF-8. Заливка —
non-zero winding, сглаживание 4×4. Память ограничена: 4096 точек, 512 контуров,
16384 отрезка, глубина составных глифов 16, ppem 1–256.

Пока нет hinting VM, CFF, переменных осей, GPOS/GSUB, кернинга,
сложной раскладки и правого направления текста. Статические файлы макета
проверяются целиком; отсутствие этих возможностей не маскируется сторонним кодом.

wm встраивает неизменённые файлы Space Grotesk Medium и JetBrains Mono Regular
в образ и хранит маски глифов в ограниченном кеше. Формат оконного ABI не меняется.
